# CRUD Simple con Login

Sistema CRUD sencillo con autenticación de usuarios.

## 📁 Archivos

- **3 HTML:** login.html, usuario.html, admin.html
- **3 CSS:** login.css, usuario.css, admin.css  
- **3 JS:** login.js, usuario.js, admin.js

## 🔑 Usuarios de Prueba

**Administrador:**
- Usuario: `admin`
- Contraseña: `admin123`

**Usuario Normal:**
- Usuario: `user`
- Contraseña: `user123`

## 🚀 Cómo Usar

1. Abre `login.html` en tu navegador
2. Ingresa con alguno de los usuarios de prueba
3. Si eres **admin**: verás el CRUD completo (crear, editar, eliminar productos)
4. Si eres **usuario**: solo verás la lista de productos

## ✨ Funcionalidades

### Admin:
- ✅ Crear productos
- ✅ Editar productos
- ✅ Eliminar productos
- ✅ Ver lista completa

### Usuario:
- ✅ Ver lista de productos

## 📱 Responsive

Todos los archivos son responsive y se adaptan a móviles.

## 💾 Almacenamiento

Los datos se guardan en `localStorage` del navegador.
